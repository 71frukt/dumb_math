## Генератор minstd

Генератор `minstd` рассчитывает числа по рекурсивной формуле
$$x_{i+1} = (a \cdot x_i + c) \mod m $$

Для векторизации выбираются параметры  
* $a = 42871$  
* $c = 0$  
* $m = 2^{31} - 1$ - число Мерсенна, выбирается таким для быстрого взятия $\mod m $.

### Быстрое вычисление $\mod m $
В случае $c = 0$ генерируемое число приобретает вид
$$y = a \cdot x \mod m, \quad m = 2^{31} - 1$$
а
$a$ занимает 16 бит, $x \le 2^{31} - 2$ - до 31 бита. $a \cdot x$ занимает до 47 бит.

$a \cdot x$ разбивается на левую и правую части битового представления
$$y = (y_1 \cdot 2^{31} + y_2) \mod m$$
$$y = (y_1 \cdot 1 + y_2) \mod m$$

$y_2$ занимает ровно 31 бит, $y_1$ занимает до 16 бит. Максимальное значение суммы $y_1 + y_2$ занимает до 32 бит, поэтому сумма также может превзойти $m$, и её так же разбиваем на две части и берем модуль суммы частей:
$$z = y_1 + y_2 = z_1 \cdot 2^{31} + z_2$$
$$y = z \mod m = z_1 + z_2$$

### Итоговая формула
```cpp
inline uint32_t MersenneMod(uint64_t x) // модуль по основанию 2^31 - 1
{
    uint64_t mod1 = (x    >> 31) + (x    & 0x7FFFFFFF);
    uint32_t mod2 = (mod1 >> 31) + (mod1 & 0x7FFFFFFF);

    return mod2;
}
```

### Skipahead
Для последующей параллелизации по потокам генератор должен иметь возможность перемещаться в состояние, которое он обрёл бы спустя определенное количество циклов работы. Для этого реализуется метод `skipahead(uint64_t offset)`. 

$$x_{i+2} = a x_{i+1} \bmod m = a (a x_i \bmod m) \bmod m = A_2 x_i \bmod m, \quad A_2 = a * a \bmod m$$

$$x_{i+\text{offset}} = A_{\text{offset}} x_{i} \bmod m, \quad A_{\text{offset}} = a^{\text{offset}} \bmod m $$

Во избежание переполнения `uint64_t` при возведении в степень $a$ берется по модулю $m$ после каждого умножения. Так как `offset` может быть огромным, а сложность возведения в степень $O(Е)$, используется функция быстрого возведения в степень по модулю $m$, сокращающая сложность до $O(\log_2 E)$, что критично при больших $N$.  
Алгоритм раскладывает показатель степени $E$ по представлению в двоичной системе счисления:
$$E = b_0 2^0 + b_1 2^1 + b_2 2^2 + \dots + b_k 2^k, \quad b_i \in \{0, 1\} $$
$$B^E = B^{b_0 2^0 + b_1 2^1 + \dots + b_k 2^k} = B^{b_0 2^0} \cdot B^{b_1 2^1} \cdot \dots \cdot B^{b_k 2^k}$$

```cpp
uint32_t FastMersenneModExp(uint64_t base, uint64_t exp)
{
    uint32_t multiplier = 1;

    while (exp > 0)
    {
        if (exp & 1)    // exp % 2 != 0
        {
            uint64_t mul = multiplier * base;
            multiplier = MersenneMod(mul);  // = mul mod m
        }

        uint64_t base2 = base * base;
        base = MersenneMod(base2);

        exp >>= 1;      // exp /= 2
    }

    return multiplier;
}

```

## Векторизация minstd
Векторный генератор оперирует упакованными по 8 32-битными `uint32_t` в AVX2 регистрах. В этом случае константа $\texttt{a}$ превращается в вектор $\texttt{a\_vec}$, состоящий из 8 элементов `jump_mult`, которые равны $a$ в степени 8 по модулю $m$. При вызове генератора возвращается текущее состояние, а следующее вычисляется по тому же методу, что в скалярной реализации, только каждый элемент вектора состояния умножается по модулю на `jump_mult`, перепрыгивая ровно через 8 генерируемых элементов.

Реализация перемножения по модулю векторов состояния `__m256i state` и множителя `__m256i mult` отличается особенностью работы с умножением упакованных в вектор чисел. Если имеется `__m256i state`$\times$`__m256i mult`, то перемножаются соответствующие элементы, стоящие на четных позициях в векторе, и записываются в вектор, хранящий 4 64-битных числа.

```C++
__m256i MinstdAVX2::StateMulMod(__m256i state, __m256i mult)
{
    // 32-bit * 32-bit = 64-bit
    // каналы 0, 2, 4, 6
    __m256i even_64 = _mm256_mul_epu32(state, mult);
    
    // нечетные каналы сдвигаются на четные позиции перед умножением
    __m256i state_odd = _mm256_srli_epi64(state, 32);
    __m256i odd_64    = _mm256_mul_epu32(state_odd, mult);

    __m256i mask_mersenne_num = _mm256_set1_epi64x(tools::MERSENNE_NUM);
    
    auto reduce = [&](__m256i x) -> __m256i {
        __m256i low   = _mm256_and_si256(x, mask_mersenne_num);     // x &= mask_mersenne_num
        __m256i high  = _mm256_srli_epi64(x, 31);                   // x >>= 31
        __m256i sum   = _mm256_add_epi64(low, high); 
        
        __m256i low2  = _mm256_and_si256(sum, mask_mersenne_num);
        __m256i high2 = _mm256_srli_epi64(sum, 31);
        return _mm256_add_epi64(low2, high2);
    };

    even_64 = reduce(even_64);
    odd_64  = reduce(odd_64);

    odd_64 = _mm256_slli_epi64(odd_64, 32);
    
    return _mm256_or_si256(even_64, odd_64);
}
```

### Vector Skipahead
Для перехода на состояние, смещенное на `offset`, каждый элемент вектора `a_vect` возводится в степень `offset * 8` по модулю $m$.
```cpp
void MinstdAVX2::skipahead(uint64_t offset)
{
    uint64_t jump_mult = FastMersenneModExp(a_, offset * 8);
    __m256i mult_vec = _mm256_set1_epi32(static_cast<uint32_t>(jump_mult));
    
    state_vec_ = StateMulMod(state_vec_, mult_vec);
}
```

## Параллелизация вычислений по потокам

Для параллелизации по ядрам используется `pthread`. Был написан модуль параллелизации для RNG, 
подробности о нём в [rng_parallelizer/readme.md](../rng_parallelizer/readme.md).

Для того, чтобы генератор был параллелизуем, он должен следовать концепту  
_определён в [rng_parallelizer/concepts.cpp](../rng_parallelizer/include/rng_parallelizer/concepts.hpp)_
```cpp
template <typename T>
concept RngParallelizable = requires(T a, uint64_t steps) {
    { a.skipahead(steps) } -> std::same_as<void>;
    { T::dimension()     } -> std::same_as<uint32_t>;    
};
```

То есть иметь метод `skipahead` и метод получения размерности `dimension` (для скалярной реализации - 1, для векторной - 8).

Замеры времени проводит модуль [benchmarking](../../benchmarking/readme.md).

Тестирующей функцией является вычисление числа $\pi$ методом Монте-Карло. В квадрате на плоскости генерируется набор двумерных векторов с случайными координатами и вычисляется число попавших в единичную окружность. В моих тестах количество векторов - 100 млн.
