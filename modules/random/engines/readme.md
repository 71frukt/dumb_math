## Генератор minstd
Генератор `minstd` рассчитывает числа по рекурсивной формуле
$$x_{i+1} = (a \cdot x_i + c) \mod m $$

Для векторизации выбираются параметры  
* $a = 42871$  
* $c = 0$  
* $m = 2^{31} - 1$ - число Мерсона, выбирается таким для быстрого взятия $\mod m $.

### Быстрое вычисление $\mod m $
В случае $c = 0$ генерируемое число преобретает вид
$$y = a \cdot x \mod m, \quad m = 2^{31} - 1$$

$a$ занимает 16 бит, $x \le 2^{31} - 2$ - до 31 бита. $a \cdot x$ занимает до 47 бит.

$a \cdot x$ разбивается на левую и правую части битового представления
$$y = (y_1 \cdot 2^{31} + y_2) \mod m$$
$$y = (y_1 \cdot 1 + y_2) \mod m$$

$y_1$ занимает ровно 31 бит, $y_2$ занимает до 16 бит. Максимальное значение суммы $y_1 + y_2$ занимает до 32 бит, поэтому сумма также может превзойти $m$, и её так же разбиваем на две части и берем модуль суммы частей:
$$z = y_1 + y_2 = z_1 \cdot 2^{31} + z_2$$
$$y = z \mod m = z_1 + z_2$$

### Итоговая формула
```cpp
inline uint32_t MersenneMod(uint64_t x) // модуль по основанию 2^31 - 1
{
    uint64_t mod1 = (x    >> 31) + (x    & 0x7FFFFFFF);
    uint32_t mod2 = (mod1 >> 31) + (mod1 & 0x7FFFFFFF);

    return mod2;
}
```
